# 🐍 [2026-01] 나만의 파이썬 소프트웨어 개발 프로젝트

## 1. 시나리오 제목
*  안녕, 일본: 성공적인 정착을 위한 경제 가이드


## 2. 시나리오 (5~10줄)
**이 프로그램은 낯선 땅 일본으로 떠나는 예비 워홀러들의 든든한 주머니 사정을 책임지는'경제 정착 시스템'입니다.
*가장 먼저 워홀을 가기 전에 이름과 현재 보유한 예산 그리고 예상되는 항공권 비용과 초기 숙박비(야칭)가 얼마인지 물어보는것으로 시작됩니다.이후 입력받은 금액들을 바탕으로 정착에 필요한 총비용을 계산하고,현재 환율을 적용하여 엔화로 환산했을때의 돈을 산출 해 봅니다. 이렇게 계산된 예산이 넉넉하다면'안정적인 시작'이라는 긍정적인 메시지를 보여주고, 만약 예산이 부족해 보인다면 '긴급 절약'이 필요하다는 조언과 함께 아르바이트가 시급하다는 판정을 내려줍니다.만약 예산도 넉넉하고 일본어 실력도 출중하다면 '퍼펙트 워홀러'라는 칭호와 함께 특별 맛집 리스트를 추천해주는 기능도 포함 할 것입니다.나중에는 단순히 초기값만 계산하는것이 아니라,일본 생활 중 발생하는 다양한 지출 내역(식비,교통비,쇼핑등)을 커다란 가계부 주머니(리스트)에 차곡차곡 담아 언제든 나의 소비 습관을 한눈에 확인 할 수 있게 만들것입니다. 마지막으로 이 모든 기능은 사용자가 메뉴판에서 번호를 눌러 지출을 입력하거나 잔액을 확인하는등 자유롭게 선택 할 수 있고,귀국(프로그램 종료)을 선택하기 전까지는 매일의 경제활동을 기록하고 관리 할 수 있는 스마트한 워홀 전용 경제 소프트웨어로 완성될 계획입니다.

## 🟩 [2차 과제: V1.0] 입출력 + 리스트 + 조건문 - 향후 작성 예정
### **✨2차 과제 내용:**
  * 이번 과제에서는 사용자의 데이터 입력 및 출력, 등급 판정이 핵심입니다
  
  * input()으로 사용자로부터 이름,자금,엔화 환율,체류기간등의 정보를 입력 받습니다
  * 비행기 표와 비자를 제외 하고 환율을 적용해 엔화를 출력합니다
  * 리스트를 만들고 이후에 있을 지출계산을위한 카테고리를 for문과 append()를 이용해 추가합니다
  * 조건문을 이용해 현 자금에 대한 등급을 내립니다
  * 중첩 if문을 이용해 현 자금에 맞는 조언을 해줍니다
    
### **🤖 AI 파트너십 과정**
1. **내용 1: 환율을 계산 하기 위한 식 도출**
    * **프롬프트 요약:** "엔화 환율을 입력 했을때 원화를 엔화로 바꾸는 식을 파이썬으로 나타내줘"
    * **적용 내용:** 일본 엔화를 원화로 바꾸는 식을 어떻게 나타내야하는지를 자세하게 알려줬고 출력할때 원하는 소수점의 위치를 설정하는 방법도 알려줬다(몰랐던 부분을 알게되었다)

2. **내용 2: 리스트조작을 위한 메소드 함수 종류와 추천**
    * **프롬프트 요약:** 리스트를 조작하기 위한 메소드 함수에는 뭐가 있고 내 프로그래밍에 어울리는 것도 추천해줘"
    * **적용 내용:** 기본적인 append(),insert() 이외에 sort(),reverse(),clear()등을 추천해줬고 나는 그중에 sort를 선택해서 프로그래밍에 넣음.여러가지 메소드를 알 수 있어 좋았다
    
### **🛠️ Troubleshooting & 기술 회고:**
1. **문제 1: 입력을 했는데 출력이 안되는 에러 발생**
    * **원인:** f-string 에서 변수 사용시 {}를 사용해야하는데 사용하지 않음
    * **해결:** {변수 이름}을 이용해 출력을 문제없이 진행
2. **문제 2: 조건문 뒤에 자꾸 생기는 빨간 줄 (SyntaxError)**
    * **원인:** if중첩에서 조건에 맞는 문장이 실행이 안되는 문제가 발생
    * **해결:** 들여쓰기의 위치를 확인하지않았음,중첩에서는 특히 들여쓰기를 신경쓸것을 상기하고 칸에 맞게 들여쓰기 진행

## 🟨 [3차 과제: V3.0] 무한 루프와 메뉴 시스템 (반복문) - 향후 작성 예정
### **✨3차 과제 업데이트 내용:**
  * 저번과제에서는 워홀러의 여러 정보를 입력 받았다면 이번과제에서는 실제 일본으로 떠난뒤 알바를 하며 생기는 수입/지출/저축액을 계산하는 프로그램입니다.

    1. 전역변수를 선언합니다.
    2. 3개의 함수(1.알바 정보 입력 2.예상 월급 계산 3.목표 적축 가능여부 분석)를 정의합니다.
    3. while True문을 이용해 함수를 호출하며 값들을 넣습니다.
    
### **🤖 AI 파트너십 과정**
 1. **내용 1**
    * **프롬프트 요약:**  3개의 함수를 정의해야하는데 어떤 함수들이 있을까?

 2. **내용 2**
   * **프롬프트 요약:** while True 문과 함수 호출을 같이 쓸 틀을 잡아줘
   * * **적용 내용:** while True문과 함수 호출문을 어떻게 같이 써야할지 막막했는데 ai가 틀을 잡아줘 앞으로 나아갈수 있었다
